# Java-Umschulung-PSS

Dieses Repository dokumentiert meinen Java-Lernweg als Fachinformatiker fuer Systemintegration (FISI) in der Umschulung. Der Fokus liegt auf Programming and Structured Software Development (PSS) mit einer klaren, schrittweisen Lernkurve.

Es werden bewusst keine Java-Quelltexte und keine fertigen Loesungen bereitgestellt. Das Repository dient als Lernportfolio, in dem Aufgaben, Lernziele, Diagramme und die fachliche Entwicklung nachvollziehbar festgehalten werden.

## Didaktische Leitlinie

Die Reihenfolge orientiert sich an einem klassischen Einstieg in Java:

- Eingabe und Ausgabe mit Scanner
- Variablen, Datentypen und Operatoren
- Entscheidungen mit `if / else` und `switch`
- Schleifen mit `for`, `while` und `do-while`
- Methoden mit Parametern und Rueckgabewerten
- Objektorientierung mit Klassen, Konstruktoren, Kapselung, Vererbung und Assoziationen

So entsteht ein Portfolio, das sowohl den Lernfortschritt als auch die Arbeitsweise sichtbar macht.

## Rahmen

Dieses Repository bleibt absichtlich konservativ aufgebaut:

- keine Frameworks
- keine Datenbanken
- keine Netzwerktechnik
- keine Enterprise-Architektur
- keine Multithreading-Themen
- keine Build-Plugin-Komplexitaet

Der Fokus liegt auf sicherem Grundlagenverstaendnis, sauberer Fachsprache und nachvollziehbarem Lernfortschritt.
