# Aufgabe: Taschenrechner

Erstelle einen textbasierten Taschenrechner mit einer Auswahl ueber ein einfaches Menue.

Der Benutzer soll eine Rechenart auswaehlen und zwei Zahlen eingeben. Danach soll das Ergebnis angezeigt werden. Die Aufgabe dient dem Ueben von `switch` und der klaren Strukturierung eines kleinen Programms.
