# Portfolio Description

Ich dokumentiere hier meinen Java-Lernweg als FISI-Umschulungsteilnehmer mit Schwerpunkt auf Programming and Structured Software Development.

Das Repository zeigt, wie ich von einfachen Konsolenprogrammen zu kleinen objektorientierten Fachmodellen arbeite. Der Fokus liegt auf sauberer Anforderungserfassung, verständlicher Dokumentation und schrittweiser Steigerung der fachlichen und technischen Komplexität.

Besonders geeignet für GitHub-Profile und Bewerbungen ist dieses Repository, weil es Lernfortschritt sichtbar macht, Grundkenntnisse in Java strukturiert belegt und eine professionelle Arbeitsweise im Umgang mit Aufgaben, Anforderungen und Dokumentation zeigt.
